# Support & Community for API Routes Explorer

Welcome to the **API Routes Explorer** support page! If you have encountered an issue, have a question, or wish to suggest an enhancement, please follow the channels below.

---

## 1. Documentation & Guides

Before filing an issue, check the official documentation:
- [README](README.md): Quick start, framework support, HTTP Client instructions, and usage details.
- [Changelog](CHANGELOG.md): History of capabilities, enhancements, and fixes.
- [Brand Guidelines & UI System](BRAND_GUIDELINES.md): Typography, color palette, and design philosophy.

---

## 2. Reporting Issues & Bugs

If you find a bug, inaccurate route detection, or unexpected behavior:

1. **Check existing issues**: Search [GitHub Issues](https://github.com/hussnain-143/api-route-explorer/issues) to see if the issue is already tracked.
2. **Open a new issue**: Provide detailed reproduction steps:
   - Framework & version (e.g. Express 4.x / 5.x, Next.js 14 App Router, Fastify 4.x, NestJS 10.x)
   - Route snippet or folder structure
   - Expected behavior vs. actual behavior
   - VS Code version and OS (macOS, Linux, Windows)
   - Do NOT include proprietary secrets, private tokens, or database passwords in your report.

---

## 3. Feature Suggestions

To suggest a new capability or framework support:
- Open a feature request in the [GitHub Issue Tracker](https://github.com/hussnain-143/api-route-explorer/issues).
- Describe the developer problem, use case, and recommended workflow.

---

## 4. Security Disclosures

If you discover a security vulnerability or sensitive data handling concern:
- Do NOT open a public issue.
- Please report confidentially via GitHub Security Advisories or contact maintainer [Hussnain Ahmed](https://github.com/hussnain-143).
- Vulnerabilities are prioritized and patched immediately.
