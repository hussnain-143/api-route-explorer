Release History

Changelog

All notable changes and architectural milestones for API Route Explorer are documented here.

v1.5.0 Latest Production October 2026

Production Release Candidate completion, final extension hardening, and multi-page public developer documentation.

  • Feature Freeze: Core MVP capabilities locked with 250 passing automated tests and zero TypeScript/ESLint warnings.
  • Documentation & Site: Launched multi-page product site with real screenshots and interactive preview.
  • Packaging: Lean VSIX bundle (59 files, 647 KB) excluding development bloat and temporary artifacts.
  • Validation: Verified against live Express backend (118 routes analyzed, 0 collision bugs).
v1.4.0 October 2026

HTTP Client Hardening, Parameter Resolution & Response UX.

  • Dynamic Parameters: Dedicated UI inputs for :id, {id}, and [id].
  • Request Tabs: Clean organization across Params, Headers, Body, and cURL generation.
  • Error UX: Friendly network diagnostics for ECONNREFUSED, ETIMEDOUT, and ENOTFOUND.
  • Socket Teardown: Safe cancellation of active in-flight requests.
v1.3.0 October 2026

Native HTTP Client Webview integration.

  • Embedded Webview: Native HTTP client side panel running securely with strict CSP.
  • Local Execution: Direct socket dispatching from the developer's Node.js host to local servers.
  • Response Inspection: Status badges, timing duration, payload size, and syntax-highlighted JSON.
v1.2.0 October 2026

OpenAPI 3.0.3 Specification Generation & Export.

  • Automated Spec: Derives complete OpenAPI 3.0.3 paths, parameters, and operation schemas.
  • Dual Serializer: Single-click export to deterministic JSON and YAML.
  • Path Privacy: Strips machine operating system paths to prevent accidental repository leaks.
v1.1.0 October 2026

Multi-Framework Expansion & Route Health Diagnostics.

  • Framework Coverage: Added Next.js (App & Pages Router), Fastify, and NestJS parsers.
  • Health Engine: Conflict detection for shadowed dynamic routes and duplicate collisions.
  • Grouping Modes: Group by File, Framework, HTTP Method, and Health status.
v1.0.0 October 2026

Initial MVP Release.

  • Core Engine: Offline AST route parser for Express applications.
  • TreeView: Interactive sidebar tree view in the Activity Bar.
  • Source Jump: 1-click jump from tree item directly to controller declaration line.
