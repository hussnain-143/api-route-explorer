Multi-Framework Intelligence

Built for your backend architecture.

API Route Explorer detects route patterns across the leading Node.js and TypeScript frameworks using static syntax trees.

Express.js

Application instances, modular routers, and nested router mounts.

Verified
routes/user.routes.tsExpress 4.x / 5.x
const router = Router();

// Detected: GET /api/v1/users/:id
router.get('/:id', authMiddleware, getUserById);

// Nested mount resolved: app.use('/api/v1/users', router);

Resolves prefix chaining across app.use('/prefix', router) mounts, detects dynamic parameters (:id), and extracts chained middleware handlers.

Next.js App Router

Route handler files in app/api/**/route.ts.

Verified
app/api/users/[id]/route.tsNext.js 13+ / 14 / 15
// Detected: GET /api/users/{id}
export async function GET(req: Request, { params }: { params: { id: string } }) {
  return Response.json({ user: params.id });
}

// Detected: DELETE /api/users/{id}
export async function DELETE(req: Request) { ... }

Extracts named HTTP method exports (GET, POST, PUT, DELETE, PATCH) and normalizes bracket dynamic routes ([id]) and catch-all routes ([...slug]).

Next.js Pages Router

File-based API routes in pages/api/**/*.ts.

Verified
pages/api/users/[id].tsNext.js Pages
// Detected: ANY /api/users/{id}
export default async function handler(req: NextApiRequest, res: NextApiResponse) {
  if (req.method === 'GET') { ... }
}

Maps API route file paths under pages/api, supporting single-file endpoints and dynamic folder segments.

Fastify

Instance verbs, route options, and modular plugins.

Verified
src/plugins/items.tsFastify 4.x / 5.x
// Detected: GET /items/:id
fastify.get('/:id', { preHandler: [auth] }, async (req, reply) => {
  return { id: req.params.id };
});

// Plugin prefix: fastify.register(itemsPlugin, { prefix: '/items' });

Discovers shorthand methods (fastify.get, fastify.post) as well as full fastify.route({...}) configuration objects with pre-handlers.

NestJS

Controller classes, method decorators, and parameter tokens.

Verified
src/users/users.controller.tsNestJS 9.x / 10.x
@Controller('users')
export class UsersController {
  // Detected: GET /users/:id
  @Get(':id')
  @UseGuards(AuthGuard)
  findOne(@Param('id') id: string) { ... }
}

Inspects class-level @Controller('path') prefixes and maps method decorators (@Get, @Post, @Put, @Delete, @Patch) with active guards.
