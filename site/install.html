Installation Guide

Install API Route Explorer

Get started in under 30 seconds. Available via the official VS Code Marketplace, command line, or offline VSIX package.

Method 1: Direct in VS Code (Recommended)

Install directly from inside your editor without leaving your window:

  1. Open Visual Studio Code.
  2. Press Cmd+Shift+X (macOS) or Ctrl+Shift+X (Windows/Linux) to open the Extensions view.
  3. Search for API Route Explorer.
  4. Click Install.
Open in VS Code Marketplace ↗

Method 2: Command Line (CLI)

Run this single terminal command in your terminal:

Terminal (bash / zsh) 
code --install-extension api-route-explorer.api-route-explorer

Method 3: Offline VSIX Package

For air-gapped environments or manual installations:

  1. Download the latest api-route-explorer-1.5.0.vsix from GitHub Releases.
  2. Install via terminal:
    Terminal
    code --install-extension api-route-explorer-1.5.0.vsix --force
Download VSIX from GitHub Releases ↗

System Requirements

  • VS Code: Version ^1.90.0 or later.
  • OS: macOS, Windows, Linux, or WSL (Windows Subsystem for Linux).
  • Backend Projects: Express.js, Next.js (App Router or Pages Router), Fastify, or NestJS.
  • Dependencies: Zero external runtime dependencies required.
