OpenAPI 3.0.3 Generation

Transform discovered backend endpoints into standardized OpenAPI 3.0.3 specifications. Export complete API schemas in JSON or YAML format without configuring complex build pipelines.

Why OpenAPI from Code?

Keeping Swagger/OpenAPI documentation in sync with fast-moving backend codebases is traditionally prone to human error and drift. API Route Explorer inspects your actual code definitions and extracts:

  • Accurate Path Templates: Translates dynamic segments (such as :id or [id]) to OpenAPI compliant curly braces {id}.
  • HTTP Verbs: Maps get, post, put, delete, patch, options, and head into valid operation objects.
  • Path Parameters: Automatically derives required parameter definitions with string types for detected dynamic path tokens.
  • Operation IDs & Tags: Groups endpoints into OpenAPI tags using detected controller names or top-level route segments.

Generating OpenAPI Documentation

You can generate an OpenAPI specification for your entire workspace or inspect a single endpoint:

1. Workspace Export (JSON / YAML)

Open the Command Palette (Cmd+Shift+P) and search for:

  • API Route Explorer: Export OpenAPI as JSON
  • API Route Explorer: Export OpenAPI as YAML

The extension compiles your discovered routes and prompts you to choose whether to open the generated spec in a new VS Code editor tab or save it directly to a workspace file (e.g. openapi.json or openapi.yaml).

2. Route-Level OpenAPI Preview

Right-click any route item in the Activity Bar tree and select Copy OpenAPI Operation to grab the specific OpenAPI snippet for that route to your clipboard.

OpenAPI Specification Format

The output strictly adheres to the OpenAPI 3.0.3 standard, making it instantly compatible with Swagger UI, Redoc, Postman import, and API gateways:

Generated openapi.yamlOpenAPI 3.0.3
openapi: 3.0.3
info:
  title: Workspace API
  version: 1.0.0
  description: Generated by API Route Explorer for VS Code
paths:
  /api/v1/users/{id}:
    get:
      summary: Get user by ID
      tags:
        - Users
      parameters:
        - name: id
          in: path
          required: true
          schema:
            type: string
      responses:
        '200':
          description: Successful response
        '404':
          description: User not found
    delete:
      summary: Delete user
      tags:
        - Users
      parameters:
        - name: id
          in: path
          required: true
          schema:
            type: string
      responses:
        '204':
          description: Successfully deleted

Zero Runtime Dependency

Unlike tools that require booting your backend server, executing decorators, or mounting Swagger middleware at runtime, API Route Explorer builds the OpenAPI document entirely via offline AST inspection:

  • Does not execute server code or initialize database connections.
  • Works even if environment variables are missing or backend databases are offline.
  • Generates clean, deterministic output in milliseconds.
