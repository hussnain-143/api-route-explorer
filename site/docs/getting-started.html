Getting Started

Get up and running with API Route Explorer in under 2 minutes. Follow this step-by-step workflow to explore your API routes.

Step 1: Open a Backend Project

Open any workspace containing an Express.js, Next.js (App Router or Pages Router), Fastify, or NestJS project in VS Code.

Step 2: Access API Route Explorer

Click the dedicated API Route Explorer icon in the VS Code Activity Bar (left sidebar).

Tip: If routes are not automatically scanned upon opening, click Scan Routes in the View title bar or press Cmd+Shift+P and select API Route Explorer: Scan Workspace.

Step 3: Explore and Group Routes

Discovered routes appear organized in an interactive tree view. Use the grouping actions to switch perspectives:

  • Group by File (Default): Endpoints grouped under their source controller file.
  • Group by Framework: Routes segmented by Express, Next.js, Fastify, or NestJS.
  • Group by Method: Organized by HTTP verb (GET, POST, PUT, DELETE, PATCH).
  • Group by Health: Filtered by Healthy, Warning, or Error status.

Step 4: Test in Native HTTP Client

Hover over any endpoint in the tree and click the Test API action icon. A native HTTP Client panel will open beside your code with the HTTP method, route signature, and base URL already configured.

If the route contains dynamic parameters (such as :id or [id]), enter test values in the Params tab, then click Send (or press Cmd+Enter).

Step 5: Export OpenAPI Specification

To generate an OpenAPI 3.0.3 specification from your discovered routes, click the OpenAPI icon in the view title bar. You can choose to export as JSON or YAML directly to your workspace.
