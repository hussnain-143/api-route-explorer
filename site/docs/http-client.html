Native HTTP Client

Execute HTTP requests against your local or development servers directly from your editor. Pre-populate endpoints, interpolate path parameters, attach headers, and view structured responses without opening third-party tools.

Opening the Client

You can launch the HTTP Client Webview panel through multiple workflows:

  • Activity Bar Route Click: Click the Test (⚡) icon next to any route item in the sidebar tree.
  • Right-Click Context Menu: Right-click a route in the tree and choose Test in HTTP Client.
  • Command Palette: Press Cmd+Shift+P and run API Route Explorer: Open HTTP Client.

Interface Overview

The HTTP Client consists of two synchronized panels: the Request Builder on the left (or top), and the Response Inspector on the right (or bottom).

Dynamic Path Parameters

When you open a parameterized route like /api/v1/users/:id or /api/v1/posts/[slug], API Route Explorer automatically detects every token and populates the Params tab with editable input rows:

  • Parameter keys are pre-filled and marked as required based on the route definition.
  • Entering a value dynamically replaces the parameter in the resolved URL preview in real time.
  • Supports Express style (:id), Next.js style ([id], [...slug]), and OpenAPI style ({id}).

Query Parameters & Custom Headers

Add arbitrary query strings and HTTP request headers through the key-value editor:

  • Query Parameters: Appends formatted query parameters (e.g. ?page=1&limit=20) with automatic URI encoding.
  • Headers: Standard presets like Content-Type: application/json and Authorization: Bearer <token> are easily inserted.

Request Body (JSON)

For mutation methods (POST, PUT, PATCH), the Body tab provides an embedded JSON editor with syntax highlighting and JSON validation before transmission.

cURL Generation & Export

Clicking the cURL button formats the entire request — including verb, resolved URL, query params, headers, and body payload — into a standard POSIX-compliant cURL command copied directly to your clipboard.

Generated cURL ExampleClipboard Output
curl -X POST http://localhost:5000/api/v1/users \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer token_xyz" \
  -d '{"name":"Alex","email":"alex@example.com"}'

Response Inspector & Metrics

When a request completes, the response panel displays:

  • Status Code: Color-coded badge (e.g. 200 OK, 201 Created, 404 Not Found, 500 Server Error).
  • Timing: Millisecond roundtrip latency (e.g. 42 ms).
  • Payload Size: Formatted body size (e.g. 1.4 KB).
  • Formatted JSON Body: Collapsible, syntax-highlighted response viewer with one-click copy.
  • Response Headers: Tabulated key-value list of returned HTTP response headers.

In-Flight Request Cancellation

If a long-running query or hung backend connection is taking too long, click Cancel. API Route Explorer immediately signals an internal AbortController on the active Node HTTP request, releasing local sockets cleanly.

Local-First Execution Architecture

Unlike cloud-hosted API clients, requests made in API Route Explorer run locally on your system using Node's native http and https modules:

  • No traffic routes through external proxies or SaaS servers.
  • Localhost ports (e.g. localhost:3000, 127.0.0.1:8080) resolve directly on your loopback adapter.
  • Your credentials and secret tokens stay exclusively in your local VS Code workspace.
