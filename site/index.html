OpenAPI 3.0.3

Turn discovered routes into documentation.

Generate complete, compliant OpenAPI 3.0.3 specifications from discovered endpoints without writing JSDoc tags or Swagger decorators.

openapi.yaml OpenAPI 3.0.3 
openapi: 3.0.3
info:
  title: API Route Explorer Workspace
  version: 1.0.0
paths:
  /api/v1/users/{id}:
    get:
      summary: GET /api/v1/users/{id}
      parameters:
        - name: id
          in: path
          required: true
          schema:
            type: string
      responses:
        '200':
          description: Successful response

Privacy & Security

Your code stays on your machine.

A developer tool built with a strict offline, zero-telemetry architecture.

What API Route Explorer Does

✓ Local Static Parsing: Analyzes code syntax trees locally without running untrusted code.
✓ Direct Local Transport: HTTP client requests are sent directly to the local port you specify.
✓ Safe Relative Paths: Generated OpenAPI files strip absolute machine directories to prevent leakage.
✓ Strict CSP: Webview panels enforce nonce-based execution with default-src 'none'.

What API Route Explorer Never Does

✗ No Telemetry or Tracking: Zero analytics beacons, telemetry pings, or usage trackers.
✗ No Account or Cloud Sync: No logins, sign-ups, or remote cloud servers involved.
✗ No .env Scanning: Secret environment files are explicitly excluded from workspace scanners.
✗ No Credential Harvesting: Authorization headers and tokens are never persisted or logged.
