Continuous Workflow

One seamless developer journey.

No copy-pasting URLs. No third-party clients. Everything connects right inside your IDE.

1

Discover

Zero runtime execution. Instant static AST scans find every route in your workspace.

2

Analyze

Detect duplicate routes, shadowed endpoints, missing handlers, and extract middleware stacks.

3

Test API

Launch the native HTTP Client pre-populated with method, base URL, and path parameters.

4

Inspect

Inspect status codes, response headers, millisecond latency, payload sizes, and formatted bodies.

5

Document

Generate valid OpenAPI 3.0.3 YAML and JSON specifications without manual annotations.

Core Capabilities

Engineered for real-world backend engineering.

Everything you need to navigate, test, and document backend APIs without leaving VS Code.

⚡

1-Click Source Navigation

Click any endpoint to jump straight to its exact controller declaration line and column in your editor.

🔍

Fuzzy Search & Filters

Search across thousands of endpoints by path, HTTP method, module folder, or handler function name.

🩺

Route Health Diagnostics

Automatic detection of route shadowing, parameter collisions, duplicate paths, and missing handlers.

🛠️

Native HTTP Client

Send GET, POST, PUT, PATCH, DELETE requests. Configure path params, query params, headers, and JSON bodies.

📋

cURL Generation

One-click copy of reproducible, formatted cURL commands reflecting your exact parameters, headers, and body.

📄

OpenAPI 3.0.3 Export

Export standardized OpenAPI YAML and JSON specifications with zero absolute machine path leakage.

Framework Compatibility

Full support for the modern Node.js ecosystem.

Robust, AST-based parsers designed to understand nested routes, decorators, and folder conventions.

EXPRESS

Express.js

  • app.get(), router.post()
  • Nested router prefixes
  • Chained route middleware
  • Dynamic :params normalization
NEXT.JS

Next.js

  • App Router (route.ts GET/POST)
  • Pages Router (pages/api/**)
  • Dynamic & catch-all routes ([id])
  • Route groups (parentheses)
FASTIFY

Fastify

  • fastify.get(), fastify.route()
  • Plugin prefix resolution
  • preHandler & preValidation
  • Multi-method route arrays
NESTJS

NestJS

  • @Controller() decorators
  • @Get(), @Post(), @Delete()
  • @UseGuards() extraction
  • Controller prefix chaining
Privacy & Security First

Built for enterprise confidentiality.

Your code, credentials, and network requests stay strictly on your local computer.

  • 🔒
    Zero Cloud Synchronization: All route indexing, AST parsing, and request dispatch happens locally.
  • 🚫
    No .env Scanning: We deliberately ignore environment files, secret files, and private keys.
  • 🛡️
    Strict CSP & Nonces: Webviews execute under strict Content Security Policies with zero unsafe-eval.
  • 👤
    No Account Required: No registration, no telemetry, no tracking pixels, zero analytics beacons.
