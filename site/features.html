Product Capabilities

Engineered for real-world backend workflows.

Every feature is designed to eliminate context switching and bring API navigation, testing, and documentation directly into VS Code.

🧭 Route Intelligence & Navigation

⚡

Offline AST Parsing

Static analysis parses route signatures safely without executing runtime application code or side effects.

🎯

1-Click Source Navigation

Click any endpoint in the tree to jump directly to its controller definition line and column in your editor.

🔍

Fuzzy Search & QuickPick

Press Cmd+P to search endpoints by HTTP method, route path, handler token, or controller file name.

🗂️

Multi-Dimensional Grouping

Switch between Group by File, Group by Framework, Group by HTTP Method, or Group by Health status instantly.

🩺

Conflict & Shadowing Detection

Flags parameterized routes that shadow static endpoints (e.g. /users/:id shadowing /users/me).

🛡️

Middleware Stack Inspection

Inspect active middleware chains, Fastify pre-handlers, and NestJS @UseGuards() decorators.

⚡ Native HTTP Client

🔌

Zero-Configuration Launch

Click "Test API" on any route to open the HTTP client with HTTP verb, base path, and route context pre-loaded.

🧩

Dynamic Path Parameters

Automatically derives input fields for :id, {id}, or [id] and substitutes them cleanly into the request URL.

📝

JSON Body & Headers Editor

Configure custom request headers and format JSON payloads with syntax error checks prior to sending.

⏱️

Millisecond Response Inspector

Measures roundtrip socket latency, status codes, payload bytes, pretty-printed JSON body, and response headers.

📋

Reproducible cURL Export

Generates exact, copyable terminal cURL commands matching your active parameters, headers, and request body.

🛑

In-Flight Cancellation

Abort hanging or slow requests with clean socket teardown without freezing your VS Code window.

📜 OpenAPI 3.0.3 Specification

✨

Automated Spec Builder

Compiles a valid OpenAPI 3.0.3 document from discovered routes without requiring manual annotations or YAML maintenance.

👁️

Route-Level Preview

Click "View OpenAPI" to preview a single route's YAML operation definition side-by-side with your code.

💾

Deterministic Export

Export your entire backend API catalog to standard JSON or YAML. Strips private machine paths for safe commits.
