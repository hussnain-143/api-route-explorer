Privacy Architecture

Your code stays on your machine.

API Route Explorer was built from day one on a strict local-first architecture. We make no external network requests, collect zero telemetry, and harvest no credentials.

What The Extension Does

✓
Local AST Scanning: Route signatures are detected using pure static syntax analysis on your local machine. No code is executed.
✓
Direct Local Socket Transport: HTTP requests from the built-in HTTP client are dispatched strictly to the target host and port you configure (e.g. http://localhost:5000).
✓
Workspace-Relative Path Normalization: Exported OpenAPI JSON and YAML documents strip absolute operating system paths, preventing accidental machine leaks in git commits.
✓
Strict Content Security Policy: Webview panels enforce cryptographic nonce script execution and default-src 'none' to prevent remote injection.

What The Extension Does NOT Do

✗
No Telemetry or Tracking: Zero analytics pings, zero usage tracking, and zero phone-home network requests.
✗
No Account or Cloud Sync: No user registration, no API keys, and no intermediary servers syncing your request history.
✗
No .env File Scanning: Secret environment files (.env, .env.local, *.pem) are explicitly ignored by workspace indexers.
✗
No Credential Harvesting: Authorization headers and bearer tokens are never logged or persisted outside active in-memory webview state.

Responsible Security Disclosure

If you identify a security vulnerability, unintended data exposure, or Content Security Policy discrepancy, please report it confidentially via GitHub Security Advisories or contact the maintainer directly. Security advisories are treated with high priority and patched immediately.
